# E-commerce Sales Data Analysis

## Project overview
This project analyzes sample e-commerce sales data using Python,
Pandas, and Matplotlib.

## Objectives
- Load and validate a CSV dataset.
- Clean missing values and invalid records.
- Calculate revenue and business metrics.
- Create bar, line, and pie charts.
- Generate a written report with insights.
- Export cleaned data and summary tables.

## Folder structure
- data/: Input dataset.
- visualizations/: Generated charts.
- report/: Analysis report and numerical summaries.
- main.py: Complete analysis pipeline.
- requirements.txt: Required packages.

## Installation
Python 3.10 or newer is recommended.

Install dependencies:
    python -m pip install -r requirements.txt

Run the project:
    python main.py

## Generated outputs
The program creates:
- cleaned_sales_data.csv
- category_sales.csv
- monthly_sales.csv
- sales_by_category.png
- monthly_sales_trend.png
- category_revenue_distribution.png
- analysis_report.md

## Dataset
The included dataset is synthetic sample data for educational
purposes. It is not real company sales data.

## Error handling
The program validates required columns, checks numeric fields,
handles missing values, and reports file or data errors.
